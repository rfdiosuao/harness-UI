Structure

harness 该有哪些组件：三层

每个行业都可以有专用的 harness，但它们共用同一套骨架。不同的只是中间那一层，最外面再换皮。

01

通用核心

任何 harness 都要有。它们对应人在回路里的五个时刻：看（进度、证据）、判（审阅、把握）、批（授权）、改（编辑、回退）、控（中断、重试）。

    带圆点的已经展出，点一下直接进展厅。

    02

    行业专用

    不同行业的差别在三样东西：要处理的对象、风险有多大、证据长什么样。

      03

      皮肤

      同一个组件可以换很多种视觉世界。风险越高的行业，皮肤越要克制：老虎机放在翻译助手里很好玩，放进大额转账的确认页就不合适。

        Interface

        每件展品都遵守同一个接口

        • 01
          数据进：window.card.set(props)可以反复调用，也可以分批给。还没到的字段先显示骨架，位置留好，不会跳动。
        • 02
          动作出：hx-action 事件用户的每一次操作都是一个事件，带上动作名和参数，交给 Agent。
        • 03
          单个文件，随处可嵌每件展品都是独立的 HTML，不用任何框架；加上 ?embed=1 就只剩组件本身，&theme=dark 切深色。
        agent.js
        // Agent → 卡片：数据可以分批到
window.card.set({ state: 'ready', spend: 3.82, cap: 10 });

// 卡片 → Agent：用户的每个动作都是一个事件
document.addEventListener('hx-action', (e) => {
  const { name, params } = e.detail;
  // 例如 { name: 'set-cap', params: { cap: 20 } }
});
        embed.html
        <iframe
  src="components/cost-ticker--lab-instrument.html?embed=1&theme=dark"
  title="费用计数"></iframe>
