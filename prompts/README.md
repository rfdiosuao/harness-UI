# 组件提示词（随机组合器）

目标：批量生成 **Agent 在回答里画给用户的卡片**，每张都有自己的视觉世界和动效，再收成组件库。

不再写死几套提示词，而是一个组合器：每次从池子里抽 **卡片 × 视觉世界 × 动效 × 限制 × 场景**，拼成一条能直接复制的提示词。

| 池 | 数量 | 例子 |
|---|---|---|
| 卡片 | 38 | 外卖下单确认、打车进度、吃药提醒、合同条款高亮、危险操作确认、澄清追问、记忆更新、把握程度…… |
| 视觉世界 | 20 | 机场翻牌屏、热敏小票、液晶计算器、地铁线路图、航海海图、蓝晒图、木刻版画、拨盘电话、穿孔卡、陶瓷釉面、磁带随身听…… |
| 动效 | 12 | 弹簧按压、逐字吐出、磁吸拖拽、墨水晕染、撕开、盖章、抽屉、翻页、一个惊喜…… |
| 限制 | 10 | 只用两种颜色、160px 小组件、单手可用、只用键盘、带合成音效、几乎没有文字、极端数据、流式进场、高对比无障碍…… |
| 场景 | 16 | 筹备 12 人的生日聚会、带父母第一次出国、独立开发者今晚发 1.0、和房东谈续租…… |

完整清单：`node prompts/roll.mjs --list`；要加新的，直接改 [pools.json](pools.json)。

**每张卡片都标注了适合的 harness**（比如合同条款高亮卡 → 法律审查，转账确认卡 → 金融支付）。抽出来的提示词里会写明，并要求生成的页面把它写进 `<head>` 的 `hx-harness` 和标题下的一行小字。只想为某一类 harness 抽卡：`node prompts/roll.mjs --harness 法律审查`。

**还有侧边栏组件**（会话列表、文件树、任务队列、上下文书架、子 Agent 名册、案卷侧栏、患者信息侧栏……共 13 种）。它们不是回答里的卡片，而是常驻在工作台一侧、跟着 Agent 实时更新的面板。抽到它们时，提示词会换成面板的写法：竖长、占满高度、内部滚动，还要能收起成窄条。只抽侧边栏：`node prompts/roll.mjs --form sidebar`。

**也能抽一整套 harness**：`node prompts/roll.mjs --whole`。一次抽「行业 harness × 布局 × 视觉世界 × 动效 × 限制」，提示词里会带上这类 harness 是谁在用、要做什么、风险多大，以及它该有的一组组件，要求做成一整个能用、组件之间互相联动的工作台。现在有 12 种 harness（法律审查、个人理财、开发运维、健康医疗、客服工单、出行差旅、研究检索、编程、自由职业工作室、通用助手、团队群聊、带支付的任务执行）和 7 种布局（三栏、对话 + 抽屉、对话 | 产物分屏、驾驶舱、单栏专注、看板、群聊）。团队群聊是人和多个 Agent 在同一个群里干活：@ 派活、Agent 之间交接、群里拍板的事自动记下来，抽它最好钉住群聊布局：`--whole --harness team-group --layout group-chat`。高风险的 harness 不会抽到玩具皮肤。想要极简的皮肤加 `--minimal`（视觉世界只从极简单线、极简字排、极简几何里抽），比如 `--whole --minimal --harness general --layout split-artifact --motion silky` 就是一套极简丝滑的通用助手。**整套 harness 的规矩（抽卡器强制写进每条提示词）**：
- **骨架**：每套都必须有 8 样——对话流、输入框、会话列表、Agent 干活的过程（思考 / 计划 / 工具调用）、人在回路（权限确认、交还控制权、暂停接手）、运行状态（模型、用量、费用、上下文）、产物、出错和恢复。抽到的行业组件是加在骨架上的，不是替换骨架。`--list` 最上面能看到这份清单（在 `pools.json` 的 `skeleton` 里改）。
- **对话永远是主体**：布局只决定会话列表、任务、产物这些面板放哪，不能把对话收进角落或浮窗；每个布局的写法里没提“对话”，抽卡器会直接报错。有的布局只适合特定的 harness（比如群聊只给 `team-group`），在布局上写 `only`。
- **极简只是风格**：`--minimal` 只换外观，组件、状态、操作和联动一样都不能少。
- **第一性原理**：UI 按金字塔原理排信息（结论先行、以上统下、归类分组、逻辑递进、视觉层级跟着信息层级），动效按迪士尼动画 12 原则来做（时间节奏、缓入缓出、预备动作、挤压拉伸、跟随与重叠、弧线、演出……）。单件和整套的提示词结尾都带着这一段。

带支付的任务执行（`task-pay`）是 Agent 替用户办一件要花钱的事：拆步骤、调工具，走到付款时把收款码、这笔钱付给谁、对应哪一步放在同一个组件里，用户核对后自己扫码付；它带了付款前核对、收款码、支付结果、任务执行侧栏四个组件，比如 `--whole --harness task-pay --layout board`。钉住某一项：`--whole --harness legal-review --layout three-pane`（harness 也可以写中文，比如 `--harness 法律`）。

通用助手 harness 用到的通用组件（模型切换、附件卡、代码块、产物面板、语音输入、限流等待、图片查看器、引用选择器、新消息提示、分享与导出）是按“一个 AI 工作台通常有哪些功能块”整理的选题清单，外观全部由抽到的视觉世界决定，不照搬任何现有产品。已经做好的组件见 [../components/INDEX.md](../components/INDEX.md)。

## 怎么随机

```bash
node prompts/roll.mjs                 # 出 1 条
node prompts/roll.mjs -n 6            # 出 6 条（同一次里卡片、视觉世界不重复）
node prompts/roll.mjs -n 6 -s 42      # 固定种子，可复现
node prompts/roll.mjs --card flight-card --world split-flap   # 钉住几项，其余随机
```

输出里每个 ` ```text ` 块就是一条完整的提示词，整块复制发给生成工具即可，结尾已经带了通用要求。

不想开终端，可以直接用 [samples.md](samples.md)：种子 2026 抽出的 6 条。

## 每张卡片的接口

生成出来的卡片都遵守同一个接口（提示词里已写好），这样才能进同一个库：

- `window.card.set(props)`：Agent 把数据传进来，可以反复调用，只给一部分数据时显示骨架。
- 用户操作时触发 `document.dispatchEvent(new CustomEvent('hx-action', { detail: { name, params } }))`。
- 页面上方有“模拟 Agent”面板，能切换所有状态；底部有“Agent 回传”小条，显示最近一次动作的 JSON。
