# 组件提示词（随机组合器）

目标：批量生成 **Agent 在回答里画给用户的卡片**，每张都有自己的视觉世界和动效，再收成组件库。

不再写死几套提示词，而是一个组合器：每次从池子里抽 **卡片 × 视觉世界 × 动效 × 限制 × 场景**，拼成一条能直接复制的提示词。

| 池 | 数量 | 例子 |
|---|---|---|
| 卡片 | 38 | 外卖下单确认、打车进度、吃药提醒、合同条款高亮、危险操作确认、澄清追问、记忆更新、把握程度…… |
| 视觉世界 | 20 | 机场翻牌屏、热敏小票、液晶计算器、地铁线路图、航海海图、蓝晒图、木刻版画、拨盘电话、穿孔卡、陶瓷釉面、磁带随身听…… |
| 动效 | 12 | 弹簧按压、逐字吐出、磁吸拖拽、墨水晕染、撕开、盖章、抽屉、翻页、一个惊喜…… |
| 限制 | 10 | 只用两种颜色、160px 小组件、单手可用、只用键盘、带合成音效、几乎没有文字、极端数据、流式进场、高对比无障碍…… |
| 场景 | 16 | 筹备 12 人的生日聚会、带父母第一次出国、独立开发者今晚发 1.0、和房东谈续租…… |

完整清单：`node prompts/roll.mjs --list`；要加新的，直接改 [pools.json](pools.json)。

**每张卡片都标注了适合的 harness**（比如合同条款高亮卡 → 法律审查，转账确认卡 → 金融支付）。抽出来的提示词里会写明，并要求生成的页面把它写进 `<head>` 的 `hx-harness` 和标题下的一行小字。只想为某一类 harness 抽卡：`node prompts/roll.mjs --harness 法律审查`。已经做好的组件见 [../components/INDEX.md](../components/INDEX.md)。

## 怎么随机

```bash
node prompts/roll.mjs                 # 出 1 条
node prompts/roll.mjs -n 6            # 出 6 条（同一次里卡片、视觉世界不重复）
node prompts/roll.mjs -n 6 -s 42      # 固定种子，可复现
node prompts/roll.mjs --card flight-card --world split-flap   # 钉住几项，其余随机
```

输出里每个 ` ```text ` 块就是一条完整的提示词，整块复制发给生成工具即可，结尾已经带了通用要求。

不想开终端，可以直接用 [samples.md](samples.md)：种子 2026 抽出的 6 条。

## 每张卡片的接口

生成出来的卡片都遵守同一个接口（提示词里已写好），这样才能进同一个库：

- `window.card.set(props)`：Agent 把数据传进来，可以反复调用，只给一部分数据时显示骨架。
- 用户操作时触发 `document.dispatchEvent(new CustomEvent('hx-action', { detail: { name, params } }))`。
- 页面上方有“模拟 Agent”面板，能切换所有状态；底部有“Agent 回传”小条，显示最近一次动作的 JSON。
